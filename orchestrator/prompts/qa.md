## 증거
증거 디렉터리 `{{evidenceDir}}` 에 실제 브라우저 캡처를 저장하고 `{{evidenceDir}}/manifest.json` 을 아래 형식의 JSON 배열로 작성한다.

```json
[{"scenarioId":"시나리오 id","steps":[{"step":1,"action":"실제로 수행한 동작과 관찰 결과","screenshot":"scenario-01.png","ts":"실제 캡처 시각의 ISO 8601 문자열"}]}]
```

- 모든 시나리오의 id를 scenarioId로 사용하고, steps에 실제로 검증한 단계와 캡처를 넣는다.
- screenshot은 위 증거 디렉터리 기준 상대 경로이며 실제 PNG 파일이 존재해야 한다. 캡처는 마지막 코드 변경 후 생성한다.
- 코드를 읽거나 조작 결과를 추측한 것만으로 통과를 주장하지 않는다. 파일이나 이미지를 위조하지 않는다.
- 브라우저 정책상 저장소 직접 조회가 불가능하면 실제 새로고침 전후 목록·완료·삭제 상태를 관찰하고 직접 조회의 한계를 기록한다.
- 필요한 서버가 이미 떠 있으면 현재 작업 디렉터리의 앱인지 확인한 뒤 사용한다. 직접 시작한 서버는 검증을 마친 뒤 종료한다.

## 출력 계약
JSON 하나만 출력한다: `{"scenarios": [{"id": string, "passed": boolean}]}`
